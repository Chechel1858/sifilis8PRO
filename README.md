# 🖥️ Nexus Monitor Pro (i3-overlay-pro)
Элегантный и интерактивный системный монитор для Linux, написанный на Python с использованием Tkinter. Идеально подходит для тайловых оконных менеджеров (i3wm, Sway, Hyprland), работает как стильное плавающее окно по нажатию горячей клавиши.
## ✨ Ключевые возможности
 * 📊 **Продвинутый Дашборд:** Графики нагрузки CPU, детальная статистика по каждому ядру, мониторинг RAM, накопителя, температуры и батареи.
 * 🌐 **Сетевой монитор:** Отслеживание скорости скачивания и отдачи, а также высокоточный живой график задержки (Ping).
 * ⚙️ **Умный диспетчер задач:** Топ процессов с сортировкой по потреблению ресурсов и **живым поиском/фильтром** по названию.
 * 🎨 **Смена тем на лету:** Встроенные палитры оформления (Catppuccin Mocha, Cyberpunk Neon, Nord).
 * 🪟 **Оптимизация для TWM:** Легко настраивается как всплывающий виджет.
## 🛠 Зависимости
Для работы программы требуется Python 3, Tkinter и библиотека psutil.
**Для Ubuntu / Debian / Linux Mint:**
```bash
sudo apt update
sudo apt install python3 python3-tk python3-pip -y
pip3 install psutil

```
**Для Arch Linux / Manjaro:**
```bash
sudo pacman -S python python-pip tk --noconfirm
pip install psutil

```
## 🚀 Установка
 1. Размести исполняемый файл i3-overlay-pro в удобной директории (например, в ~/sifilis/).
 2. Сделай файл исполняемым:
   ```bash
   chmod +x ~/sifilis/i3-overlay-pro
   
   ```
 3. Проверь запуск вручную из терминала:
   ```bash
   ~/sifilis/i3-overlay-pro
   
   ```
## ⌨️ Интеграция с оконными менеджерами
Чтобы монитор работал как всплывающий виджет, его нужно правильно прописать в конфигурации твоего оконного менеджера.
### Настройка для i3wm
Открой конфигурационный файл i3 (обычно ~/.config/i3/config) и добавь в конец следующие строки:
```i3config
# ==========================================
# Настройки Nexus Monitor Pro
# ==========================================

# Горячая клавиша для запуска (Mod + Shift + O)
bindsym $mod+Shift+o exec --no-startup-id ~/sifilis/i3-overlay-pro

# Правила для окна (сделать плавающим и задать размеры/позицию)
for_window [title="Nexus Monitor Pro"] floating enable
for_window [title="Nexus Monitor Pro"] resize set 480 700
for_window [title="Nexus Monitor Pro"] move position right bottom

```
После сохранения файла перезагрузи конфигурацию i3, нажав Mod + Shift + R. Теперь по нажатию Mod + Shift + O виджет будет аккуратно появляться в правом нижнем углу экрана.
### Настройка для Hyprland
Если планируешь использовать на Wayland/Hyprland, добавь это в ~/.config/hypr/hyprland.conf:
```ini
# Бинды запуска
bind = $mainMod SHIFT, O, exec, ~/sifilis/i3-overlay-pro

# Правила окна
windowrulev2 = float, title:^(Nexus Monitor Pro)$
windowrulev2 = size 480 700, title:^(Nexus Monitor Pro)$
windowrulev2 = move 100%-490 100%-710, title:^(Nexus Monitor Pro)$

```
## 💡 Использование
 * **Навигация:** Используй вкладки на верхней панели для переключения между разделами.
